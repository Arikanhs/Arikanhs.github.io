## What it does

Image2ASCII converts an image into text art. The image is split into a grid of
cells; each cell's brightness picks a character from a ramp such as
`" .:-=+*#%@"`, and the character is drawn in the color sampled from the image.
The ASCII backgrounds on this site use the same idea.
